# Cotización Instagram · MGD & DUKE

Página web de la cotización n.º 2026-012 (Plan Básico de gestión de Instagram).

- Todo está en `index.html` (HTML + CSS + JS, sin dependencias ni compilación).
- Para verla: abre `index.html` en el navegador o publícala con GitHub Pages (Settings → Pages → rama principal, carpeta raíz).
- El botón «Descargar PDF» usa la impresión del navegador con una hoja de estilos de impresión limpia.
- El botón «Aceptar propuesta» abre WhatsApp; el número está en la constante `WHATSAPP` dentro del script.
- Logos de las marcas en `assets/`.
